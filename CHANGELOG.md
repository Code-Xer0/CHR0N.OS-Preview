# Changelog

## v0.1.0-beta.1

First public Windows preview with installer and portable distribution lanes.

Includes:

- local-first intake and archive browsing
- provenance-preserving working copies
- Files, Explorer, Search, Dashboard, Archivist, Atlas, and Mapping surfaces
- meaning/significance sidecar scaffolding
- PDF/text/DOCX/image/video preview support where available
- setup installer, MSI package, portable zip, and SHA-256 checksum files

Known limitations:

- public beta; use test/non-critical data first
- OAuth, NAS, updater, full media inference, and WebGL Atlas optimization remain in progress
- Windows may warn on unsigned beta builds
