# Security and Privacy

CHRON.OS is designed around source-file respect: original files should remain untouched, while CHRON.OS works with copied artifacts and sidecar metadata.

This preview is local-first and experimental. Do not use it as the only copy of critical records. Do not publish private archives, credentials, vault material, or sensitive personal records to GitHub.

If you find a security issue, contact the maintainer privately rather than opening a public issue with sensitive details.
