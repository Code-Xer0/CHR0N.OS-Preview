# CHRON.OS Preview

CHRON.OS is a local-first archival intelligence preview for Windows. It helps users copy important files into a working archive, preserve provenance, inspect context, and begin assigning meaning without mutating original source files.

This repository is the public download and portfolio surface. It intentionally does not contain the full CHRON.OS source tree.

## Status

Public preview beta. Use test or non-critical data first.

Known areas still in progress:

- updater pipeline
- code signing
- NAS and cloud connector polish
- full multimodal inference
- Atlas performance optimization
- production OAuth setup

## Source Access

The public preview is distributed as an installer-first beta, with a portable ZIP available for no-install testing. Source access, internal doctrine, and active development work remain separate from this public distribution lane.
